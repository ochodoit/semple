# 🏒 퍽 드리블 트레이너

아이패드 카메라로 **흰 바닥(연습판)·스틱·퍽을 실시간 인식**해 화면에 겹쳐 보여주고,
장애물 피하기와 스틱핸들링 트레이닝을 진행하는 웹 앱입니다. 프레임워크·외부 라이브러리 없이
순수 HTML/CSS/JS(ES Modules)로 만들어졌고, 홈 화면에 추가하면 전체화면 앱처럼 동작합니다(PWA).

## 기능

| 모드 | 설명 |
| --- | --- |
| 자유 연습 | 인식 상태를 보며 자유롭게 드리블. 터치(방향 전환) 수·이동 거리·속도 표시 |
| 장애물 코스 (60초) | 바닥 위 가상 콘을 피해 타겟 통과. 콘 충돌 시 생명 -1, 시간이 갈수록 콘 추가·이동 |
| 와이드 드리블 (30초) | 좌우 끝 구역을 번갈아 터치해 가동 범위 훈련 |
| 8자 드리블 (45초) | 두 콘 사이를 8자로 돌며 게이트를 순서대로 통과 |
| 퀵 핸즈 (20초) | 가운데 박스 안에서 최대한 빠르게 좌우 터치 |
| 반응 타겟 (30초) | 무작위 타겟으로 퍽을 최대한 빨리 이동, 평균 반응 시간 측정 |

- **2인 대결**: 같은 모드를 번갈아 플레이해 점수 비교
- 모드별 최고 기록 저장, 난이도(쉬움/보통/어려움)
- 거울 모드, 인식 마스크 디버그 보기, 효과음

## 인식 방식 (의존성 없음)

1. 카메라 프레임을 240px 폭으로 축소해 매 프레임 분석합니다.
2. **바닥**: 밝고 채도가 낮은(흰색) 픽셀의 행/열 분포로 바닥 영역을 자동 감지합니다. 흰 벽 등으로 오검출되면 **바닥 고정** 버튼으로 현재 영역을 고정하거나, 설정에서 **수동 지정**(모서리 4개 드래그)으로 바꿀 수 있습니다.
3. **퍽**: 바닥 안에서 지정 색(기본 검정)의 픽셀을 연결 성분으로 묶고, 크기·원형도·직전 위치와의 거리로 가장 퍽다운 블롭을 고릅니다. 잠시 가려지면 속도로 예측(주황 원)합니다.
4. **스틱**: 보정에서 블레이드/테이프 색을 지정하면 같은 방식으로 추적합니다(마름모 마커).
5. 바닥 사각형 → 단위 정사각형 호모그래피로 게임 좌표를 만들기 때문에, 콘·타겟이 실제 바닥 위에 놓인 것처럼 원근이 적용됩니다.

## 사용 준비

1. 아이패드를 거치대에 세우고 흰 바닥(연습판)이 화면에 크게 들어오게 각도를 맞춥니다. 조명은 고르게, 바닥에 강한 그림자가 없을수록 좋습니다.
2. 앱을 열고 **카메라 시작** → 바닥이 파란 점선으로 표시되는지 확인합니다.
3. **보정** → "퍽 터치로 지정" 후 화면 속 퍽을 터치합니다(검정 퍽은 기본값으로도 동작). 스틱은 블레이드에 **주황·파랑 등 눈에 띄는 색 테이프**를 감고 같은 방법으로 지정하세요. 흰색·검정 테이프는 바닥/퍽과 구분되지 않습니다.
4. 설정 > "인식 마스크 표시"를 켜면 바닥(파랑)·퍽(빨강)·스틱(초록) 마스크를 보며 밝기/허용 오차 슬라이더를 조정할 수 있습니다.
5. **모드** 선택 후 **시작**.

## 실행

카메라(getUserMedia)는 **HTTPS 또는 localhost**에서만 동작합니다.

```bash
# 같은 Wi-Fi의 아이패드에서 테스트 (자체 서명 인증서 자동 생성, openssl 필요)
python3 serve.py
# -> https://<컴퓨터IP>:8443 을 아이패드 Safari에서 열고 인증서 경고를 통과

# 데스크톱 로컬 테스트만 할 때
python3 serve.py --http   # http://localhost:8080
```

Firebase Studio 미리보기나 Firebase Hosting / GitHub Pages 등 HTTPS 호스팅에 올리면 바로 사용할 수 있습니다.
iPadOS에서는 Safari 공유 메뉴 → **홈 화면에 추가**로 전체화면 앱처럼 실행하세요.

## 구조

```
index.html            레이아웃(HUD, 패널)
style.css             스타일
src/main.js           앱 오케스트레이션, UI, 보정, 대결 모드
src/camera.js         getUserMedia / 장치 선택
src/vision.js         바닥·퍽·스틱 인식 (마스크, 연결 성분, 선택)
src/geometry.js       호모그래피, 스캔라인
src/tracker.js        퍽 위치 스무딩·속도·터치 카운트
src/game.js           모드별 규칙·점수·결과
src/render.js         오버레이 캔버스 렌더링
src/audio.js          WebAudio 효과음
src/storage.js        설정·기록(localStorage)
serve.py              HTTPS 개발 서버
test/                 합성 영상 기반 인식 테스트 (Playwright)
```

```bash
node test/run.mjs   # 합성 프레임으로 바닥/퍽/스틱 인식 + 앱 로드 검사
```
